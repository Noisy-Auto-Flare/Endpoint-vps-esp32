# Прошивка устройств — рабочая шпаргалка

Проверено на текущем железе (ESP32-CAM AI Thinker, ESP32-C3 SuperMini, microReader на ESP8266).

## Общее

- **Программатор:** ESP32-CAM-MB (CH340) — один COM-порт на всё, что подключено через него.
  Windows: нужен драйвер CH340, порт виден в диспетчере устройств.
- **ESP32-C3** прошивается своим USB-C (USB Serial/JTAG), программатор для него не нужен.
- **Перед прошивкой сторонней платы через MB** вынь ESP32-CAM из гнезда и вынь все dupont-провода
  из breakout-разъёма: иначе TX двух устройств висят на одной линии и загрузка срывается.
- **Проверка, что чип виден:**
  ```
  esptool --port COM3 --baud 115200 flash-id
  ```
  Ответ должен содержать тип чипа, размер flash и MAC.
- **Скорость:** для ESP32/C3 через нативный USB/CH340 921600 обычно работает; для ESP8266 через
  CH340 используй **115200** — на 921600 загрузка срывается (`Invalid head of packet`).

## 1. ESP32-CAM

1. Вставь модуль в ESP32-CAM-MB: оба ряда 2×8 до упора, камера смотрит от USB, антенна наружу.
2. Подключи USB.
3. Проверь чип:
   ```
   esptool --port COM3 --baud 115200 flash-id
   ```
   Ожидается `ESP32-D0WD...`, flash 4 МБ.
4. Прошей (Arduino IDE: плата **AI Thinker ESP32-CAM**, Partition **Huge APP (3MB No OTA/1MB SPIFFS)**,
   PSRAM **Enabled**; или arduino-cli):
   ```
   arduino-cli upload --fqbn "esp32:esp32:esp32cam:PartitionScheme=huge_app" -p COM3 esp32-cam/ESP32_CAM_recorder
   ```
5. Если не синхронизируется: зажми **IO0**, нажми и отпусти **RST**, отпусти IO0 — и повтори.
6. После прошивки нажми RST (перемычка IO0 не нужна, авто-сброс работает).

Признак успеха: через ~2 с после подключения к Wi-Fi один длинный + один короткий миг, в журнале сервера — `[photo] frame ingress` и `[cam] ip change` (плата шлёт свой IP на `POST /api/device-ip`).
Веб-страница на `:80` показывает IP платы и блок «Последний отправленный кадр» — кадр подгружается только по кнопке «Показать последний кадр» (`GET /last_frame`, без автозагрузки).

## 2. ESP32-C3 (микрофон)

1. Подключи USB-C **напрямую в плату** (не через программатор).
2. В системе появится порт вида «USB Serial/JTAG» (например COM4).
3. Проверь чип:
   ```
   esptool --port COM4 --baud 115200 flash-id
   ```
   Ожидается `ESP32-C3`, embedded flash 4 МБ.
4. Прошей:
   ```
   arduino-cli upload --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" -p COM4 esp32-c3/microphone
   ```
   Arduino IDE: **ESP32C3 Dev Module**, Flash 4MB, Partition **Default 4MB**, **USB CDC On Boot: Enabled**.
5. Кнопка записи — **внешняя, GPIO3 → GND** (INPUT_PULLUP); BOOT/GPIO9 — только аппаратный strap платы, прошивкой не используется. Зажатый BOOT при сбросе переводит чип в загрузчик (нужно для прошивки).
   Синий LED (GPIO8) горит всю запись и гаснет на стопе; коды 2/3/5 миганий — только на финале сессии.
6. Проверка: Serial-монитор 115200, должен быть баннер `=== ESP32-C3 Voice Chunks v2 (DMA) ===`
   и полученный IP.

## 3. microReader (ESP8266)

1. Вынь ESP32-CAM из MB и все dupont-провода из breakout.
2. На плате microReader есть 6-контактный разъём прошивки, подписи: `GND DTR TX RX RST GND`.
3. Подключение к ESP32-CAM-MB:

   | microReader | ESP32-CAM-MB |
   |---|---|
   | GND | GND |
   | TX | RXD |
   | RX | TXD |
   | DTR | **не подключать** — замыкается на GND на самой плате |
   | 5V | **не подключать** |

   Если загрузка не стартует — поменяй TX/RX местами (маркировка адаптеров бывает от разных сторон).
4. **Замкни DTR–GND перемычкой** — это и есть GPIO0 в нуле, вход в загрузчик.
5. Питание — **от аккумулятора microReader** (включи тумблер). Внешнее питание не подаётся.
6. Прошей (Arduino IDE: Generic ESP8266, `4M (FS:2MB OTA:~1019KB)`, Erase Flash: All flash).
7. Сними перемычку DTR–GND и выключи/включи питание.

### Полное стирание microReader

Если чип глючит или нужно снести настройки/RF-калибровку:

```
esptool --port COM3 --baud 115200 erase-flash
esptool --port COM3 --baud 115200 write-flash 0x0 microreader/firmware/a-microReader-v1.3.bin \
  --flash-mode dout --flash-freq 40m --flash-size 4MB
```

После полного стирания настройки пустые. При первом включении поднимись точкой доступа
`Reader AP` / `00000000`, зайди на `192.168.4.1` и заново укажи Wi-Fi и вкладку «Сервер».

## Проверка после прошивки

| Устройство | Что должно быть |
|---|---|
| ESP32-CAM | длинный + короткий миг через 2 с после Wi-Fi; веб-страница на `:80` показывает IP и блок «Последний отправленный кадр» (по кнопке, `GET /last_frame`); в журнале сервера `[photo] frame ingress` и `[cam] ip change` |
| ESP32-C3 | баннер в Serial и IP; нажатие кнопки — `[voice] chunk` в журнале сервера |
| microReader | главное меню; в Меню 3 строка режима сначала `Режим: ...?`, после включения мониторинга — подтверждённый режим |

## Частые проблемы

- **`Invalid head of packet` / `No serial data received`** — чип не в загрузчике, плохой контакт,
  ESP32-CAM оставлен в сокете MB, или длинные провода. Сними лишнее, передёрни питание, снизь скорость до 115200.
- **921600 срывается на CH340** — используй 115200.
- **microReader после прошивки не стартует** — не снята перемычка DTR–GND (чип остался в загрузчике).
- **microReader показывает FS ~64 КБ вместо 2 МБ** — собрано с неверным Flash Size.
  Перепрошей по USB с `4M (FS:2MB OTA:~1019KB)` и `Erase Flash: All flash`.
- **CAM не синхронизируется, хотя порт есть** — проверь питание модуля (3.3 В на пине 3V3)
  и посадку в сокет: сдвиг на один пин = нет питания.
